野火音频编辑 2.0.2 · GG 小程序卡密版

授权与激活
本程序与 yuansheng（原声工坊 V7 / 野火音乐台）共用 GG-XXXX-XXXX-XXXX 卡密。
启动自动联网校验本机 GG 授权，未激活时显示输入窗口。支持体验卡、日卡、月卡、年卡、永久卡；体验卡要求为首次激活起 24 小时，具体卡种与期限由小程序后台签发，客户端不能自行延长。
顶部授权按钮可随时查看类型和到期时间、重新校验或更换卡密。已有有效 GG 授权时直接复用本机设备身份，重复输入先校验，不重复占用设备名额。主动更换卡密也会切换本机野火音乐台使用的 GG 授权。
开始处理前以及运行期间定期联网检查授权；卡密到期、被停用或校验失败后停止新处理，正在处理的未完成结果安全取消，已完成文件保留。音频处理不扣卡密次数。
授权身份受 Windows 当前用户保护，安装在其他盘或重装仍保留；安装包不含本机卡密或设备身份。首次使用需联网，不提供客户端自选卡种、自动续期或离线绕过。

一、使用方法
1. 点击“添加音频”或“添加文件夹”，也可直接拖入文件。
2. 选择快捷预设，或在右侧输入精确参数。
3. 选择输出格式、保存位置，点击“开始处理”。
4. 完成后点击“打开结果”。原音频不修改，输出保持原文件名。

二、参数怎么调
快捷预设（速度 / 音调 / 播放速率）：
轻度：105.00% / -1.00 半音 / 102.00%。
中度：110.00% / -1.50 半音 / 104.00%。
重度：115.00% / -2.00 半音 / 105.00%。
点击预设会同时设置三项参数，仍可继续手动微调；“原始”恢复为 100.00% / 0.00 半音 / 100.00%。
速度：只变快慢，音调保持。100.00% 为原速；105.00% 表示快 5%；90.00% 表示慢 10%。轻快可先试 103～108%，练习可先试 85～95%。
音调：只变高低，速度保持。0.00 为原调；+1.00 升半音，-1.00 降半音。先从 ±0.50～2.00 半音试听。
播放速率：同时改变快慢和高低。通常保持 100.00%。需要整体快一点、高一点可先试 103.00%；该项与速度叠加，例如两项都为 105%，总速度约为 110.25%。
三项均可输入两位小数，右侧小箭头每次增减 0.01；滑块适合粗调，数字框适合精调。按 Tab 或点击其他位置确认输入。
常用建议：只想变快，就只调“速度”；只想升降调，就只调“音调”；其余保持原始值。
选中一首歌曲后可点击“试听选中歌曲”，调整参数可实时试听。试听包含速度、音调、播放速率和音量；峰值统一、转单声道在导出时生效。未检测到扬声器时仍可导出。
预计时长仅供参考，算法缓冲和编码可能带来少量差异。

三、文件夹、歌词与重名文件
提交文件夹后自动查找子目录中的支持音频；默认保留目录结构。
同一目录、同一主文件名的 .lrc / .txt / .srt / .ass / .vtt 歌词会随结果复制。
歌词原样复制，不重新计算歌词时间轴；调整歌曲速度后歌词可能需要重新对时。
默认跳过已存在的同名结果。需要重做时，可在“更多设置”勾选替换已有结果。
若输出路径与提交的原音频相同，会将结果放入“处理结果”子文件夹，保护原文件。
多个输入映射到同一个结果名时会提示，请保留目录结构或分批提交。

四、更多设置
默认根据可用内存和处理器数量安排 1～8 首并行；配置较低时自动减少。可关闭自动并行，逐首处理。
输出音量 100% 为原音量，80% 为八成。峰值统一开启后会统一峰值至约 -0.2 dBFS，并覆盖常规音量比例；不等同于响度均衡。
音乐通常保留立体声；需要语音文件时可选择单声道。
算法微调通常保持：片段 0、搜索 0、重叠 8 毫秒。
高级算法参数由处理库决定实际支持精度；数值越大不代表效果越好。

五、格式与歌曲信息
支持 MP3、WAV、OGG、AAC/M4A、AIFF 等输入，单声道或立体声。
支持 MP3、WAV、OGG、M4A 输出。WAV 为 16 位 PCM；MP3 可选 128/192/256/320 kbps；OGG 使用品质 6，M4A 使用编码器品质 100。
采样率沿用输入。新版不支持多声道输入。
“编辑歌曲信息”用于修改导出 MP3 的标题、歌手、专辑、年份、曲目和备注。默认读取原 MP3 的这些常用文本信息；封面和其他扩展标签不包含在此版本的元数据导出范围内。
停止后保留已完成的结果，正在处理的未完成音频不作为结果发布。

六、运行与版本
适用于 Windows 10/11，需要系统自带的 .NET Framework 4.x。
这是独立编写的本地处理程序，使用随包音频处理组件；不启动原 Audio Speed Changer Pro。GG 授权通过小程序云端校验，音频和歌词仍在本机处理，不上传到卡密服务器。
设置和处理记录保存在 %LocalAppData%\WildfireAudioEditor。处理记录可在软件内查看。
本版不包含原程序的外壳右键扩展、在线帮助和全部附加功能。
第三方音频组件信息见“第三方组件说明.txt”。
